## 👋 About me

I'm a **Geneva-based AI / Machine Learning Engineer and Software Engineer** working across **generative AI, computer vision, data engineering, full-stack development and software architecture**.

I like turning real-world problems into maintainable tools: collecting and structuring data, experimenting with models, building **APIs and user interfaces**, and designing the systems, tests and delivery workflows around them. My projects range from **enterprise RAG assistants and geospatial automation** to **data-driven SaaS products and reusable software platforms**.

**What I work on:**
- **LLMs & knowledge systems:** Retrieval-Augmented Generation (RAG), embeddings, semantic search, vector databases and document intelligence.
- **Machine learning & vision:** deep learning, model fine-tuning, object detection, segmentation and multimodal workflows.
- **Backend & data engineering:** Python, FastAPI, PostgreSQL, ETL, SQL, data pipelines and workflow automation.
- **Product & platform engineering:** TypeScript, React, Angular, Astro, reusable Web Components, shared data contracts, monorepos, automated tests and reproducible builds.

## 🧩 Product & platform engineering

Alongside AI work, I'm developing a **private, in-progress monorepo** for modular, data-driven business applications and decision-support tools. It brings together software architecture, product thinking and engineering practices:

- **Monorepo architecture & builds:** **Bazel**, **pnpm**, modular applications, reusable packages and reproducible build/test targets.
- **Frontend & design systems:** **Astro**, **TypeScript**, **Stencil.js Web Components**, design tokens and **Storybook**; component integration across **React and Angular** environments.
- **Typed data architecture:** **PostgreSQL**, **Drizzle ORM**, **Zod**, database schemas and migrations, row-level security concepts, and shared TypeScript interfaces/contracts between data and applications; **Supabase** integration is part of the platform roadmap.
- **Testing & developer experience:** **Vitest**, **Playwright**, browser-level component tests, **TSDoc / TypeDoc**, component documentation and development tooling.
- **Business-oriented software:** workflows for strategic analysis, decision support and data-driven management, informed by business and MBA concepts.

*This platform is under active development. The private source code isn't presented as an open-source release or a finished production product.*
